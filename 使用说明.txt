光伏大数据项目 — 使用说明（速查）

【工程位置】
  桌面 Git：/root/Desktop/光伏项目框架
  后端安装：/opt/module/photovoltaic
  前端安装：/home/webspace/solarweb
  运行 jar：/opt/module/photovoltaic/information/photovoltaic-information-0.0.1-SNAPSHOT.jar

【目录】
  photovoltaic/   后端（common / datagenerate / information / spark / sparkrdd）
  solarweb/       前端 Vue2
  demo/           演示
  deploy/         部署
  big-data-notes/ 说明
  docs/PROGRESS.md 功能进度

【常用命令】
  # 构建 information
  cd /root/Desktop/光伏项目框架/photovoltaic
  mvn -DskipTests clean package -pl photovoltaic-common,photovoltaic-information -am

  # 启动后端（master）
  cd /opt/module/photovoltaic/information
  nohup java -jar photovoltaic-information-0.0.1-SNAPSHOT.jar >> run.log 2>&1 &

  # 启动前端
  cd /home/webspace/solarweb && npm run serve   # :8080

【接口】
  POST http://master:8113/screen/ammeter          电表读数
  GET  http://master:8113/screen/stationMonthPower 本月发电量/效率

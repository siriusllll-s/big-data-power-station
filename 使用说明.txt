光伏大数据项目 — 使用说明（速查）

【仓库结构】（根目录即为工程，无嵌套 big-data-power-station-main）
  photovoltaic/   后端 common / datagenerate / information / spark / sparkrdd
  solarweb/       前端 Vue2
  demo/           演示
  deploy/         云部署
  docs/PROGRESS.md 功能进度
  docs/sql/       建表脚本

【常用命令】
  # 建电价/合同表
  mysql -h slave2 -uroot -p123456 photovoltaic < docs/sql/station_management.sql

  # 构建 information
  cd photovoltaic
  mvn -DskipTests clean package -pl photovoltaic-common,photovoltaic-information -am

  # 启动后端
  java -jar photovoltaic-information/target/photovoltaic-information-0.0.1-SNAPSHOT.jar

  # 启动前端
  cd solarweb && npm run serve   # :8080

【电站管理接口】
  GET  /station/detail/1
  POST /station/save
  POST /station/savePhoto
  POST /stationSolarPrice/pageByParam | /save | GET /detail/{id} | GET /delete/{id}
  POST /stationContract/pageByParam   | /save | GET /detail/{id} | GET /delete/{id}
  GET  /dictionary/province | /city/{id} | /area/{id}
  POST /minio/upload

【大屏接口】
  POST /screen/ammeter
  GET  /screen/stationMonthPower
  GET  /screen/stationLastThirtyDayPower/1
  GET  /screen/stationMonthKWhStatistic/1
  GET  /screen/stationFaultCount/1

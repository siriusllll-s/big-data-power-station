## 一、电站管理-电站信息

### 用例13 显示电站详细信息

| 项 | 内容 |
|----|------|
| 前置条件 | 已登录；数据库存在电站数据 |
| 测试数据 | 电站 id=1（简称：唯一电站） |

步骤：
1. 登录系统，点击左侧菜单「电站管理」→「电站信息」
2. 观察页面展示内容

预期结果：
1. 顶部核心指标卡片展示：装机容量（MWp）、运行状态（运行中/建设中/未开工/维修中，`status`）、电站类型（分布式/地面式/大棚电站，`type`）、并网时间、模拟发电效率（%）、协议效能比（%）
2. 电站图片区展示电站照片（`detail.photoPath`）
3. 电站名称、电站简称、电站描述（`stationDesc`）
4. 地址区展示：省/市/区（`province.province` + `city.city` + `area.area`）+ 详细地址（`address`）
5. 人员信息：维护人员（`maintainPersonObj.name`）、电站负责人（`stationPersonObj.name`）
6. 其他信息：销售类型（全额上网/自发自用/余电上网）、建设周期、所属人（`own`）等
7. 页面右上角显示【上传图片】【编辑】按钮

接口验证：`GET /station/detail/1` 返回 `successful=true`，含上述字段。
> 自动化：用例13 已覆盖（通过 shortName 断言；注：DB 中 name 字段为空，属历史数据问题）。

### 用例14 电站图片

| 项 | 内容 |
|----|------|
| 前置条件 | 已登录；准备一张本地图片（jpg/png） |
| 测试数据 | 任意小尺寸图片（≤1MB） |

步骤：
1. 进入「电站管理」→「电站信息」
2. 点击【上传图片】按钮
3. 在弹出的文件选择框中选中本地图片并确认
4. 上传完成后观察页面

预期结果：
1. 点击【上传图片】弹出文件选择窗口
2. 选择图片后自动上传，页面电站图片区域更新为上传的新图片
3. 图片可正常显示（可访问预览地址 `GET /minio/preViewPicture/<key>`，返回 200）
4. 页面无报错

接口链路：`POST /minio/upload`（multipart，参数 file）→ 返回 key；`POST /station/savePhoto`（body：station/photo）→ 保存；预览走 `/minio/preViewPicture/**`。
> 自动化：用例14a/14b/14c 已覆盖（上传/保存/预览，并还原原图）。

### 用例18 新增电价

| 项 | 内容 |
|----|------|
| 前置条件 | 已登录 |
| 测试数据 | 电价 1.05 元，实施日期 2026-08-01 |

步骤：
1. 进入「电价管理」
2. 点击【新增电价】按钮
3. 观察弹出的编辑框
4. 不录入任何数据，直接点击【确定】
5. 观察提示信息
6. 录入必填项：所属电站、电价设置、实施日期（备注可选）
7. 点击【确定】
8. 观察列表变化

预期结果：
1. 弹出「新增电价」编辑框，字段：所属电站（只读回显）、电价设置、实施日期、备注，显示为空数据
2. 编辑框标题为「新增电价」（操作已有数据时切换为「编辑电价」）
3. 不录入点【确定】：表单校验提示「请输入所属电站名称」「请输入电价设置」「请选择实施日期」，数据不提交
4. 录入必填项后点【确定】：提示保存成功，编辑框关闭
5. 列表刷新后出现新记录，分页总数 +1

接口验证：`POST /stationSolarPrice/save`（body：station/price/beginDate/memo）返回 `successful=true`，新记录可在列表/详情查询到。
> 自动化：用例18/18b 已覆盖（保存成功 + 列表可见）。必填校验为前端 el-form rules 实现，服务端无 Bean Validation，如需服务端兜底可后续补加。

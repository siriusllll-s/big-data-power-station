## 测试中发现并修复的问题

1. **缺列 `del_flag`**：`station_solar_price`、`station_contract` 表缺少 `del_flag` 列，
   导致列表/查询接口直接报 SQL 错误（Unknown column 'del_flag'）。
   已执行：
   ```sql
   ALTER TABLE station_solar_price ADD COLUMN del_flag INT DEFAULT 0 COMMENT '0正常 1删除' AFTER memo;
   ALTER TABLE station_contract  ADD COLUMN del_flag INT DEFAULT 0 COMMENT '0正常 1删除' AFTER memo;
   ```
2. **`create_time` 无默认值**：两表 `create_time` 为 NOT NULL 且无默认值，
   导致新增/编辑保存失败（Field 'create_time' doesn't have a default value）。
   已执行：
   ```sql
   ALTER TABLE station_solar_price MODIFY create_time DATETIME DEFAULT CURRENT_TIMESTAMP;
   ALTER TABLE station_contract  MODIFY create_time DATETIME DEFAULT CURRENT_TIMESTAMP;
   ```
3. **数据问题（未修改）**：电站 id=1 的 `name` 字段为空（shortName=唯一电站 正常），
   前端电站列表/编辑页会显示空名称，建议补全数据。
